# Rural Electricity Billing System

## Project Description
This project implements a rural electricity billing system using C programming. It explores data types, constants, preprocessor directives, billing calculations, input validation, and testing.

## Files
- task02.c to task12.c: Programs for the assignment tasks.
- billing.h: Shared billing declarations and constants.
- tariff.txt: Tariff configuration for Task 11.
- tariff12.txt: Tariff configuration for Task 12.

## Tariff Details
- Fixed charge: Rs 50
- First 100 units: No additional energy charge
- Units 101-200: Rs 2.25 per unit
- Above 200 units: Rs 4.50 per unit

## How to Run
1. Open a task's C source file in Dev-C++.
2. Compile and run the program.
3. Enter the requested test input.
4. Keep required configuration files in the program's working directory.

## Testing
Test normal readings, boundary values, invalid inputs, meter rollover, large totals, and peak-hour calculations where applicable.
